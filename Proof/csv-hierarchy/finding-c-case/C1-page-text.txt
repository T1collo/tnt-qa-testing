How async processing statuses work

Accepted — request received and queued (HTTP 202). Paste the Request ID from the response into Filters to find it.
Processing — validation and storage are in progress.
Succeeded — event accepted into the platform (downstream delivery may still complete separately).
Failed — validation or processing failed; fix the payload and resubmit (you get a new Request ID).

If submit returns HTTP 503, the request was not accepted — retry later. API Logs only show the HTTP accept hop; final outcome is tracked here. See the Partner Learning Center.
